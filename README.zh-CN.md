# Threshold Audit

轻量级 Python 阈值校准与检测评估组件，适用于异常检测、安全评分和二分类检测实验。
组件接收已有模型或评分规则生成的分数。运行流程为 **干净负样本校准 → 固定阈值 → 独立测试集评估**，报告整体及各分组的混淆矩阵、误报率、检出率和置信区间。运行时仅使用 Python 标准库。

[English README](README.md)

## 快速开始

需要 Python 3.10 或更高版本。在仓库根目录直接运行示例和测试。

```sh
python -m threshold_audit examples/synthetic.csv --direction higher --target-fpr 0.1 --output audit-report
python -m unittest discover -s tests -v
```

也可以从当前目录安装，再通过命令行入口运行。

```sh
python -m pip install .
threshold-audit examples/synthetic.csv --direction higher --target-fpr 0.1 --output audit-report
```

项目目前通过源码和本地安装方式使用。

### 在 Python 中调用

```python
from threshold_audit import audit, read_csv

result = audit(
    read_csv("examples/synthetic.csv"),
    target_fpr=0.1,
    direction="higher",
    comparison="strict",
)
print(result["threshold"], result["overall"])
```

## 输入数据

输入为 UTF-8 CSV 文件，支持 UTF-8 BOM。每一行对应一个样本。

| 列名 | 含义 |
|---|---|
| `sample_id` | 非空且全局唯一的样本标识 |
| `score` | 有限浮点数形式的检测分数 |
| `label` | `0` 为干净负样本，`1` 为待检出的正样本 |
| `split` | `calibration` 为校准集，`test` 为测试集 |
| `group` | 可选分组名，空值或缺失值统一归入未命名组 |

校准集和测试集均需包含样本，校准集中的标签必须全部为 `0`。样本标识在全部数据中保持唯一，跨校准集和测试集的重复标识也会触发错误。构造数据划分时，还需检查内容重复、同一用户重复出现等潜在泄漏来源。

解析器会检查重复表头、必填字段缺失、额外的无表头单元格，以及 `NaN`、无穷大等非法分数。额外的具名列会被忽略。

## 命令行参数

| 参数 | 作用 | 默认值 |
|---|---|---|
| `input` | 输入 CSV 路径 | 必填位置参数 |
| `--direction` | `higher` 表示分数越大越可疑，`lower` 表示分数越小越可疑 | 必填 |
| `--target-fpr` | 校准集上的目标经验误报率，范围为 `[0, 1]` | `0.01` |
| `--comparison` | `strict` 使用严格比较，`inclusive` 使用包含边界的比较 | `strict` |
| `--confidence` | 双侧置信区间的置信水平，范围为 `(0, 1)` | `0.95` |
| `--output` | 报告输出目录 | `audit-report` |

## 阈值如何确定

阈值选择仅使用校准集中的负样本。确定阈值后，再将同一规则应用于测试集。

| 分数方向 | `strict` 判为阳性的条件 | `inclusive` 判为阳性的条件 |
|---|---|---|
| `higher` | `score > threshold` | `score >= threshold` |
| `lower` | `score < threshold` | `score <= threshold` |

设校准样本数为 `n`，允许的误报数为 `k = floor(target_fpr × n)`。当 `k < n` 时，工具先将分数统一为“越大越可疑”的方向，再按降序排列，选取从零开始索引为 `k` 的分数作为严格比较的边界。与边界同分的样本会整体排除，因此实际校准误报率可能低于目标值。

`inclusive` 会沿可疑方向将边界移动至下一个可表示的浮点数，使两种比较方式在校准集上得到相同的判定，同时保留供下游使用的具体数值边界。目标误报率为 `1` 时，边界允许全部有限分数样本判为阳性。边界也可能取无穷大，JSON 用字符串 `Infinity` 或 `-Infinity` 表示。

工具在上述校准顺序统计量边界中，选取满足经验误报预算的最宽松边界。校准误报率的最小非零分辨率为 `1/n`。目标值为 `0` 时，校准集上的误报数为零，测试集和实际应用中的误报率仍需独立评估。

### 示例结果

仓库内的合成示例在 `--direction higher --target-fpr 0.1` 下得到判定规则 `score > 0.8`。

| 数据集 | 误报率 FPR | 检出率 TPR |
|---|---|---|
| 校准集 | `1/10 = 0.10` | 缺少正样本，记为未定义 |
| 测试集 | `1/4 = 0.25` | `3/4 = 0.75` |

示例展示了校准集与独立测试集的误报率差异。示例数据全部为合成数据。

## 输出报告

命令行默认将以下文件写入 `audit-report/`。

| 文件 | 内容 |
|---|---|
| `report.json` | 完整配置、阈值与比较符、校准和测试统计量、分组结果、置信区间、工具版本及输入文件 SHA-256 |
| `metrics.csv` | 测试集整体及各分组的样本数、类别分母、TP、FP、TN、FN、FPR、TPR 和区间 |
| `report.md` | 便于阅读的阈值、指标摘要和统计解释 |

输入哈希计算和 CSV 解析使用同一份字节快照。相同输入字节和配置可生成字节一致的报告，便于复现。CSV 导出会为看起来像公式的组名添加单引号前缀，JSON 中保留组名内容。

## 统计解释

- FPR 为负样本中被判为阳性的比例，TPR 为正样本中被正确检出的比例。
- 某个分组缺少正样本或负样本时，相应比例和区间记为未定义，在 JSON 中为 `null`，在 CSV 中留空。
- 区间采用双侧 Wilson 得分区间，默认置信水平为 95%。测试集区间的解释依赖于观测相互独立，以及阈值在测试前已经固定。
- 校准集区间用于描述参与阈值选择的同一批观测。
- 分组区间分别适用于各组。涉及多组联合结论、重复用户、相关观测、事后分组搜索或分布漂移时，需要进一步设计统计分析。
- `target_fpr` 约束校准集上的经验误报率，测试分布和实际总体上的误报率需要独立证据支持。
- 校准集应与模型训练、调参和最终测试数据分开。阈值在校准后固定，再报告测试结果。
